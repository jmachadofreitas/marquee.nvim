# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - Unreleased

### Added

- Gutter signs for primary marks (`a-z`, `A-Z`).
- `m{char}` / `dm{char}` / `dm-` / `dm<Space>` / `dm|` / `dM` mappings.
- `:MarqueeRefresh`, `:MarqueeToggleSigns`, `:MarqueeTelescope`, `:MarqueeClear`,
  `:MarqueeClearBuffer`, `:MarqueeDelete`, `:MarqueeDeleteLine` commands.
- Telescope picker filtered to primary marks, with a `:marks` fallback.
- which-key marks popup filtered to primary marks.
- `MarqueeSign` / `MarqueeSignNum` highlight groups.
- `:checkhealth marquee`.
